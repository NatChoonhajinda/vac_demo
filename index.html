    Is there Atopic Dermatitis (AD) symptom?

    Answering Yes opens the SCORAD assessment below.

    SCORAD

    SCORing Atopic Dermatitis

    A clinical tool for assessing the severity (extent, intensity) of atopic dermatitis as objectively as possible. Total score ranges from 0 to 103.

    A — Area (20% of the score)

    For each body region, select how much of that region is affected by eczema. Each region is weighted by its share of body surface area (BSA).

    A (extent)—/ 100

    B — Intensity (60% of the score)

    A representative area of eczema is selected. In this area, the intensity of each of the following signs is assessed as none (0), mild (1), moderate (2) or severe (3).

    B (intensity)—/ 18

    C — Subjective symptoms (20% of the score)

    Using a visual analogue scale where 0 is no itch (or no sleeplessness) and 10 is the worst imaginable itch (or sleeplessness).

    C (subjective)—/ 20
    SCORAD
    — / 103
    Not complete

    SCORAD = A/5 + 7B/2 + C, where A = (head + upper limbs L + upper limbs R)×0.09 + (lower limbs L + lower limbs R + back + anterior trunk)×0.18 + genitals×0.01. All 16 items must be answered before a score is reported. Severity bands are the common reference cutoffs (mild < 25, moderate 25–50, severe > 50).

    Step 4 of 5 · Screening

    Is the patient on medication?

    Answering Yes opens the daily medication score below.

    dMS

    Additive Daily Medication Score

    Selection — The total score ranges from 0 to 6

    dMS
    0 / 6
    No medication

    0 points: No medication used. Points are additive across medication classes (1 + 2 + 3 = 6). If the classes are meant to be mutually exclusive escalation tiers instead, this should be single-select 0–3 — verify with the clinical definition.
